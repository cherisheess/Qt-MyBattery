## API Reference

### Class: `MyBattery`
- Header: `mybattery.h`
- Inherits: `QWidget`
- Qt macros: `Q_OBJECT`

#### Public
- `MyBattery(QWidget* parent = nullptr)`
  - Constructs the widget and initializes colors and internal state based on the UI.
- `~MyBattery()`

#### Protected Overrides
- `void paintEvent(QPaintEvent* event) override`
  - Renders the battery frame, background fill (level), and head. Uses anti-aliasing.

#### Slots
- `void on_horizontalSlider_valueChanged(int value)` (private slot)
  - Updates the internal current level when the UI slider changes.

#### Private Helpers
- `void drawBorder(QPainter* painter)`
- `void drawBackGround(QPainter* painter)`
- `void drawHead(QPainter* painter)`

#### Behavior & Properties (internal)
- `m_currentValue` (int): The battery level (0–100). Initialized from the UI slider at startup. Updated via the slider.
- `m_alarmValue` (int, default 30): Threshold below which the fill switches to alarm colors.
- `m_minValue`/`m_maxValue` (int, 0/100): Level bounds.
- `m_normalColorStart/End`, `m_alarmColorStart/End` (QColor): Gradient colors for normal vs. alarm state.
- `m_batteryRect`, `m_thickness`, `m_borderRadius`, `m_bgRadius`, `m_headRadius`, `m_margin`: Geometry and styling parameters.

#### Notes
- There is currently no public setter/getter for the battery level or styling. The level reflects the internal `horizontalSlider` found in the UI form `mybattery.ui`.
- The widget references `ui->widget` as the drawing area rectangle.

### Class: `widget`
- Header: `widget.h`
- Inherits: `QWidget`
- Qt macros: `Q_OBJECT`

#### Public
- `explicit widget(QWidget* parent = nullptr)`
- `~widget()`

#### Purpose
- Minimal host window generated by Qt Designer. Sets up its UI in the constructor.

---

### UI Forms
- `mybattery.ui`
  - Contains a `QWidget` named `widget` used as the battery drawing area and a `QSlider` named `horizontalSlider` that controls the battery level.
- `widget.ui`
  - Basic form for the host window.

---

### Entry Point
- `int main(int argc, char* argv[])`
  - Creates `QApplication`, instantiates and shows `MyBattery` and `widget`, then enters the event loop.
